# Screenshots

Add photos of your Walrus Assassin 90 display running this driver!

## How to contribute
1. Take a photo of the display showing temperature
2. Name it `display_running.jpg` (or .png)
3. Place it in this folder
4. Submit a PR

## Requested photos
- [ ] Display showing CPU temp
- [ ] Display showing GPU temp (alternation)
- [ ] Display with case lighting
- [ ] Display in dark environment
